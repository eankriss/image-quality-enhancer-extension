# Image Quality Enhancer

Full-page Chrome/Edge extension.

Features: original-size export by default, custom width/height with aspect-ratio lock, before/after preview, sharpness/contrast/brightness/saturation controls, light/dark mode, and PNG/JPEG/WebP export.

Install: extract ZIP, open chrome://extensions/ or edge://extensions/, enable Developer mode, click Load unpacked, and select the extracted folder.

Note: enhancement is browser-based and local. It does not use a cloud AI super-resolution model.
