# Image Credit Watermark v1.1.0

Full-page Chrome / Edge extension for adding visible source credits to images.

Features:
- image upload
- source/credit field
- optional rights note
- live preview
- draggable watermark
- 9 placement presets
- text/background color controls
- opacity, font size, padding, edge margin controls
- light/dark mode
- original dimensions preserved
- PNG, JPEG, WebP export

Important: this tool adds a visible credit label only. It does not create, verify, or prove a license. Only use statements such as "Licensed for use" or "Used with permission" when they are actually true.

Install:
1. Extract the ZIP.
2. Open chrome://extensions/ or edge://extensions/.
3. Enable Developer mode.
4. Click Load unpacked.
5. Select the extracted image-credit-watermark-extension folder.

## Version 1.1.0 improvements

- Preview and downloaded image now use the exact same canvas renderer.
- Long URLs/source strings automatically wrap instead of being clipped.
- Font size, padding, opacity, background, and line wrapping now match the exported file.
- Dragging is performed directly on the rendered credit box in the canvas preview.
